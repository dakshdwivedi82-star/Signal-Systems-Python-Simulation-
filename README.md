Signals & Systems – Python Simulation

📌 Project Overview

This project demonstrates the simulation and analysis of basic Signals and Systems signals using Python.

The project uses NumPy for numerical calculations and Matplotlib for graphical visualization.

📊 Signals Simulated

The following signals are simulated:

1. Unit Step Signal
2. Unit Impulse Signal
3. Ramp Signal
4. Sinusoidal Signal
5. Exponential Signal

🛠️ Technologies Used

- Python
- NumPy
- Matplotlib
- Visual Studio Code

▶️ How to Run

Install the required libraries:

pip install numpy matplotlib

Then run:

python signal_systems.py

The program generates graphs for the different signals.

📈 Project Results

The repository contains the generated graphs for:

- Unit Step
- Unit Impulse
- Ramp
- Sine Wave
- Exponential Signal
